# AulaConecta - Front-end

## Descripción del proyecto
AulaConecta es una plataforma educativa que busca mejorar la conexión entre estudiantes y docentes a través de herramientas digitales.

## Problema que resuelve
Muchas instituciones educativas tienen dificultades para centralizar la comunicación, los materiales y el seguimiento del aprendizaje. AulaConecta soluciona esto ofreciendo una interfaz clara y organizada.

## Objetivo del front-end
Crear una interfaz moderna, responsiva y fácil de usar que permita a los usuarios acceder a las funcionalidades principales de la plataforma.

## Alcance inicial
En esta primera etapa se planea construir:
- Página de inicio (Home)
- Página de login / registro
- Dashboard del estudiante
- Vista de cursos
- Perfil de usuario

## Acuerdo de trabajo
- Toda la actividad se realiza en la rama `feature-presentacion`.
- No se edita directamente la rama `main`.
- Antes de fusionar se debe hacer una revisión entre pares.
- Los mensajes de commit deben ser claros y descriptivos.

## Criterios de calidad para aceptar una contribución
1. El código o documentación debe estar bien estructurado y legible.
2. No debe contener información sensible (contraseñas, tokens, datos personales).
3. Debe cumplir con el alcance definido en el proyecto.
4. Debe pasar por una revisión de al menos un compañero.
5. El mensaje de commit debe explicar claramente el cambio realizado.
